### SQL注入  
  
登入系统后，通过瞎注自动插入引号判断，发现注入。系统内有很多注入点，我这边就挑一个给大家展开说一下子。  
  
![](https://mmbiz.qpic.cn/mmbiz_png/mcko8AHj6QXLg6EmM9rPfibf8CHAfzeZ4iaf8eJ1zroOKB3PwVANOXpGKgjULfqIjCRUgYrbqpcuKCQeS3CmX8V5Uc0JibKayJRLRMVDVM9vqs/640?wx_fmt=png&from=appmsg "")  
接下来验证注入，这里我就不贴SQLMap的图了，最开始梭哈过，跑着跑着卡住不动了，不过这也不是第一次了，习惯了……直接手工来吧。通过响应包可见，一个单引号与两个单引号时，响应返回内容不一致，说明单引号可以对其产生影响：  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/mcko8AHj6QXO7dWpF1nAicXmqY3N9uJG1GxreHFVxeqic4uPe0SsG13zibia0ORJGQCZ2hpZ9WS3fpylTek8v7wTiaBF5S0BS0y6BsiaRKG9d5kPE/640?wx_fmt=png&from=appmsg "")  
  
![](https://mmbiz.qpic.cn/mmbiz_png/mcko8AHj6QXxl0SufL8lmoOqHWawV6KDiaWy9dItxxpm3b0IZSZic9ZCJubia2PIabVXK29Cx9un5MEaRWAcW13tjVqIBVDt9LZlh72xWtUffE/640?wx_fmt=png&from=appmsg "")  
但是，现在并不能确定单引号就是闭合符合，所以我们构造语句继续确认，语句如下：```
1'||'1'='1
1'||'1'='2

```  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/mcko8AHj6QWAvo8B6tp4zMOTEa8b8Yhm3urxjXUSsic3zOEpWAd1K2v6ZibOhVMDqibHSe0C057tib3eJicQmGdvZKic014xPfdC6URibc49dTGnLM/640?wx_fmt=png&from=appmsg "")  
啊这，正常来说如果是单引号闭合的话，上面两条语句返回的内容应该是不一致的，但是上面的语句并未生效。这说明，闭合符号可能不是单引号。那么，有可能存在括号，继续构造语句：  
```
1')||(1='1
1')||(1='2

```  
  
![](https://mmbiz.qpic.cn/mmbiz_png/mcko8AHj6QVI7U7vXNruUzS0ycqStBw5Kdaat0ibkpzUwCKcBFRBOb4KKav1HQiaz5EJgqcaZFRRfsc2pEHKkH1Z7RDoTQTqWTc5ib1RQhA9EQ/640?wx_fmt=png&from=appmsg "")  
  
![](https://mmbiz.qpic.cn/mmbiz_png/mcko8AHj6QX5DxF7tiaTyNyO1q7Kr05iaXYIiaNBrl9uTQWwN25EXLwrZeKibPwLITZacKgPXrdgIPp6eFn9R6VHfYibt1Xept0mVKAf5p9MC7ks/640?wx_fmt=png&from=appmsg "")  
  
OK，果然带括号，构造语句确认到数据库名长度为7：  
  
![](https://mmbiz.qpic.cn/mmbiz_png/mcko8AHj6QV8vhjquSkGb6mhSgz2zsO9TuCSEJ2pLLDZKkQia4WjQ21vFKFg2dzQc5YXnzaha0iaIxTjV4ZhrEloCQVxtuiax0YbdoHKHSRBj0/640?wx_fmt=png&from=appmsg "")  
接下来我们继续构造语句，来获取库名：  
```
1')||(substr('abc',1,1)='a')and(1='1
1')||(substr(database(),1,1)='X')and(1='1

```
